## 커뮤니티 복구판 현황

복구판의 지원 브라우저는 **Google Chrome**입니다. Firefox는 지원하지 않으며 Firefox 빌드·서명·자동 배포 경로를 제공하지 않습니다. 이전 기록에 있는 Firefox 검사 결과는 당시의 이력이며 현재 지원 선언이 아닙니다.

2026-10-11 후속 권한 정합성 작업에서 확장 호스트 권한과 정적·동적 주입 대상을 `https://chzzk.naver.com/*` 하나로 축소했습니다. HTTP와 치지직 서브도메인 전체 권한은 요청하지 않습니다. 미리보기·방송 시각의 `api.chzzk.naver.com` 요청은 본 사이트 MAIN 페이지 코드에서 실행되므로 API 호스트 권한을 별도로 선언하지 않지만, 아래 개인정보처리방침에 설명한 API·미디어 연결과 기존 세션 동반 가능성은 그대로입니다. 권한을 거절하거나 요청이 실패하면 안내 화면을 유지해 재시도할 수 있고, 나중에 권한을 허용하면 이전 스타일 등록 실패를 한 번 다시 시도합니다. 이 변경의 로컬 회귀는 실제 설치본·Chrome 121·스토어 심사나 전체 보안 검증을 대신하지 않습니다.

2026-10-11 패키지 검사기의 존재 여부 검사만으로 폴더를 JavaScript 리소스로 승인하는 결함을 재현하고 참조 자원의 일반 파일 여부와 각 내부 경로 구성 요소의 링크 여부를 확인하도록 보완했습니다. manifest·선택적 package 메타데이터·HTML 자원·literal worker 의존성·기본 locale에 적용하며, 패키지 루트 별칭은 유지합니다. 끊어진 메타데이터 링크는 파일 부재로 취급하지 않습니다. 신규 13건 중 11건 실패→보완 후 통과, 집중 33/33·HLS 전용 파일 제외 일반 회귀 413/413·분리 Chrome 패키지 v2.13.3/20개 진입 리소스를 확인했습니다. Astra max의 독립 기능 검토도 지적 없이 13/13을 재확인했습니다. 실제 디렉터리 접합점을 사용했으며 Windows 파일 심볼릭 링크 생성은 EPERM으로 검증하지 못했습니다. 안정된 패키지 트리의 참조 검사이지 동시 파일 교체에 대한 원자적 읽기나 전체 빌드 트리 검사는 아닙니다. 기존 설치본·HLS 보류 파일은 변경하지 않았습니다.

이 단계의 도구 재점검에서 npm 권고와 Gitleaks 현재 파일·Git 이력 탐지는 각각 0건이었습니다. 정적 경고는 기존 73건에 경로 유형 확인용 `lstat`·루트 별칭 확인용 `realpath`의 동적 파일 경로 경고 2건이 추가되어 현재 75건(객체 동적 접근 43건·동적 파일 경로 32건)이며 모두 미해결로 보존합니다. 검사기 이외의 기존 경고 68건도 그대로입니다. 경고 해제·규칙 완화나 보안 완료 판정은 하지 않았고, 공개·배포는 계속 보류합니다. 아래 73건·400건 등은 각각 이전 단계의 기록입니다.

2026-10-11 사용자 오류 화면의 `web/main.js` 종료 처리에서 `Extension context invalidated.`가 발생하면 뒤의 페이지 이벤트 정리까지 중단되는 문제를 통제된 환경에서 재현했습니다. 종료 시 두 확장 API 정리를 독립적으로 시도하고 페이지 이벤트는 반드시 해제하며, 예상된 무효화 예외만 처리하도록 보완했습니다. 다른 오류는 단일 원인 그대로 또는 복수 원인을 담아 보고하며 BFCache의 일시 정지는 최종 종료와 구분합니다. 신규 8건 중 7건 실패→수정 후 통과, 기존 설정·다중 탭을 포함한 집중 26/26·HLS 전용 파일 제외 회귀 400/400·Chrome 합성 영상 필터 17/17·분리 패키지 검사를 확인했습니다. 실제 오류가 발생한 무효화 계기·시점과 새 설치본의 확장 업데이트/재로딩 수용은 아직 확인하지 않았습니다. 기존 설치본과 HLS 보류 영역은 변경하지 않았으며 공개·배포는 계속 보류합니다.

이 종료 처리만 대상으로 한 Astra max 독립 기능 검토에서 중대·중요 결함은 없었으나, 콜백이 무반응인 상태와 실제 구독 해제를 구분하지 못하는 작은 테스트 공백이 지적됐습니다. 실제 DOM API에 전달하는 콜백·capture 조합을 기록하도록 테스트만 보강했습니다. 페이지 수명 이벤트 해제를 메모리에서 누락시키는 변형은 기존 검사 8/8을 통과했지만 보강 뒤 8/8이 실패했고, 실제 제품 코드에서는 집중 26/26·최종 일반 회귀 400/400이 통과했습니다. 검토자가 같은 차이를 독립 재확인했습니다. 제품 코드의 추가 변경이나 보안·HLS 검토가 아닙니다.

이 프로젝트는 원본 v2.13.1의 호환성 복구 변경에 별도 배포용 이름·설명·안내/지원 링크를 추가한 비공식 커뮤니티 복구판입니다. 배포 준비 기준은 `codex/community-store-preview`의 2.13.2였으며, 현재 후속 작업 브랜치 `codex/sidebar-preview-followup`의 manifest와 package 버전은 2.13.3입니다. 원작자가 승인한 공식 배포판이나 후속판이 아닙니다. 원본 저작권과 MIT/HLS.js 라이선스 고지를 유지합니다.

사용자 확인으로 스토어 등록 완료·심사 대기까지 진행했습니다. 이는 당시 보고한 상태이며 현재 심사 승인·게시 여부를 다시 확인한 결과는 아닙니다. 현재 2.13.3 후속 작업 전체가 스토어에 제출됐다는 뜻도 아닙니다. [사용 안내](https://github.com/Do-hyeon/cheese-knife/blob/main/README.md)와 [문제 신고](https://github.com/Do-hyeon/cheese-knife/issues)는 이 포크를 대상으로 합니다. 새 문서 링크는 main 기준이며, 기존 `codex/community-store-preview`의 브랜치와 문서 URL은 구버전 사용자를 위해 유지합니다. 원본 PR #81의 `codex/chzzk-compatibility-recovery`와 원본/main은 이 후속 작업으로 수정하지 않습니다. 새로운 스토어 항목은 기존 원본 설치와 별개이므로 중복 실행을 피하고, 설정 자동 공유·자동 이전을 전제로 하지 마세요.

[개인정보처리방침 / Privacy Policy](https://github.com/Do-hyeon/cheese-knife/blob/main/PRIVACY.md)은 로컬 채팅·식별자·주소·조작 이벤트 처리, 치지직 API 및 미디어 연결, 저장 위치·삭제와 제한적 사용을 설명합니다. 개발자 서버로 전송하지 않는다는 사실이 데이터 처리가 없다는 뜻은 아닙니다. 스토어에 입력하는 방침 URL은 새 패키지의 링크와 별도로 갱신해야 하며, 최신 문서 공개·접근 확인 전에는 기존 URL을 바꾸지 않습니다.

초기 배포 준비에서는 전체 Node169·native 스타일108·영상필터17 및 합성 팝업 한·영2건을 확인했습니다. [배포 준비 기록](docs/superpowers/validation/2026-10-08-community-store-preparation.md)을 참고하세요. 2026-10-11 후속 단계에서는 HLS 전용 테스트 파일을 제외한 Node391·native 스타일108·영상필터17을 확인했습니다. 미해결 도구 경고, HLS 보완 검증, 일부 실제 환경 수용은 남아 있습니다. 아래의165건·후보/대기 설명은 이전 호환성 복구 시점의 기록이며 현재 설치본·스토어 심사 승인으로 확대하지 않습니다.

현재 작업 사본에는 검증이 보류된 HLS 변경이 포함되어 있습니다. 일반 빌드는 이를 자동으로 제외하지 않습니다. Git HEAD의 기존 HLS 파일·고지와 현재 나머지 소스를 조합한 분리 시험 패키지는 검증 범위를 나눈 기록이며, 보안 문제를 해결한 차기 스토어 배포판으로 채택하지 않습니다. HLS 원복을 보안 문제의 해결로 취급하지 않으며, 미해결 경고와 검증 한계를 유지합니다. 보안 보완 및 실제 설치본 수용은 별도 완료 조건입니다.

[한글 기여 PR #81](https://github.com/jebibot/cheese-knife/pull/81)을 원본 저장소에 제출했습니다. 검증한 범위와 미검증·음질/환경 한계를 명시한 복구 시험판 기여이며 전체 정상·출시 승인이나 스토어 배포가 아닙니다. 아래 시점별 후보 기록의 대기 상태는 당시 결과이며 최신 상태는 [기여 준비 상태](docs/superpowers/validation/2026-10-08-contribution-readiness.md)를 기준으로 확인하세요.

Vue 없이 플레이어 버튼·컴프레서·VOD 길게 눌러 2배속을 제공하고 HLS.js 미리보기, 화면 전환 수명 관리, 기능별 준비 상태를 추가했습니다. [설계](docs/superpowers/specs/2026-10-08-chzzk-compatibility-design.md), [검토](docs/superpowers/reviews/2026-10-08-chzzk-compatibility-review.md), [검증 결과와 제한](docs/superpowers/validation/2026-10-08-chzzk-compatibility.md)을 함께 확인하세요.

자동 테스트 165개를 통과했으며, 별도 브라우저의 실제 오디오·공개 방송 미리보기 검증도 기록했습니다. [독립 구현 검토](docs/superpowers/reviews/2026-10-08-implementation-review.md), [실제 Chrome VOD 길게 누르기 수정 검토](docs/superpowers/reviews/2026-10-08-vod-hold-review.md), [전체 브랜치 독립 검토와 보완](docs/superpowers/reviews/2026-10-08-whole-branch-review.md)도 공개합니다. [후속 readiness 독립 검토](docs/superpowers/reviews/2026-10-08-final-readiness-review.md)의 링크·VOD 툴팁 재사용과 2배속 OFF 취소 결함을 승인된 한 번의 보완 패스로 수정했습니다. 신규14개 중12개 실패→통과와2개 보호 검사, 당시 전체Node136·스타일91·필터17을 확인했습니다. 사용자 확장 새로고침 후 [통제된 설치본 재사용·실제 VOD 입력 검사](docs/superpowers/validation/2026-10-08-restored-settings-and-runtime-checks.md)도 통과했습니다. 이후 삭제 채팅 후보와 미션·차단 CSS를 추가했고, 남은 실제 이벤트/환경 미검증을 전체 정상으로 합산하지 않는 범위로 기여 PR에 제출했습니다.

Gain 바를 48px·끝 여백 8px로 조정해 실제 라이브에서 확인했습니다. [합성 신호 음질 검사](docs/superpowers/validation/2026-10-08-audio-quality-and-gain-spacing.md)는 기본 설정의 출력과 전환 시 개선 후보를 기록하며, 실제 음성·음악의 음질 보장은 아닙니다. 오디오 처리 방식은 이번 검사에서 변경하지 않았습니다.

[후속 Gain 평활화·미리보기 지연 수정](docs/superpowers/validation/2026-10-08-gain-smoothing-follow-up.md)은 Gain을 10ms 동안 이어지게 처리하고 API 대기와 hover 지연이 중복되지 않도록 합니다. 사용자가 미리보기 정상 동작을 확인했습니다. [전체 기능 점검](docs/superpowers/validation/2026-10-08-full-feature-audit.md) 이후 왼쪽 채팅의 라이브 화면 축소를 수정하고 실제 라이브·VOD 배치와 너비 조절을 확인했습니다. 당시 검토 보완본의 설정 경쟁·미리보기 취소·팝업 드래그·상태 갱신 수정에는 설치본 새로고침이 필요했고, 후속 결과를 별도로 기록했습니다. [전체 기능 계획](docs/superpowers/plans/2026-10-08-full-feature-acceptance.md)의 미검증 항목은 유지하며 사용자가 승인한 제한 명시 기여 PR 범위와 구분합니다.

### 로컬 Chrome에서 시험하기

1. 시험할 변경 범위를 먼저 확인합니다. 현재 후속 버전은 2.13.3이며 보안 보완·검증이 미완료입니다. 현재 작업 폴더를 스토어 업데이트 완성본으로 취급하지 말고, 승인된 시험 대상만 로드합니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. 저장소 폴더(또는 빌드한 `dist`)를 선택합니다. 중복 실행을 피하려면 기존 치즈 나이프 확장은 일시적으로 꺼둡니다. 기존 설정과 확장을 삭제할 필요는 없습니다.
4. 열려 있는 치지직 탭을 새로고침합니다. 팝업의 현재 탭 상태는 기능 연결 준비를 나타내며 실제 재생/출시 검증을 대신하지 않습니다.

설치와 개발자 모드 변경은 사용자가 직접 수행합니다. 업데이트 뒤 확장 페이지에서 새로고침하고 치지직 탭도 다시 로드해야 합니다. 다른 ID로 로드한 로컬 확장은 원본 스토어 확장의 설정을 자동 공유하지 않습니다.

### 현재 제한

라이브의 새 일반 채팅 삭제에 대한 [guarded 복구 후보](docs/superpowers/validation/2026-10-08-restored-settings-and-runtime-checks.md)를 추가했습니다. JSX/서버 조회 없이 native content와 다른 listener를 보존하고 OFF/CANCEL 시 원복합니다. 초기 Node22개를 검사했고 설치본 팝업의 준비됨 및 원래 OFF 복원을 사용자 확인으로 기록했으나, 실제 자연 발생 삭제 이벤트/취소선·label은 미검증입니다. 과거 숨김 내역이나 VOD 삭제 표시를 복구하지 않습니다. 실제 미션 숨김 ON→OFF 복원도 확인했으며 실제 파티·차단 대상은 없었습니다.

[새 변경 범위 독립 검토](docs/superpowers/reviews/2026-10-08-deleted-chat-and-style-review.md)에서 외부 코드가 보관 객체를 직접 숨김/변경한 뒤 오래된 소유권이 재사용되는 결함을 확인했습니다. 현재 NORMAL·유형·식별자·본문 일치를 요구하고 불일치 기록을 폐기하도록 보완해7실패→통과/삭제29개/전체165·스타일108·필터17 및 빌드·패키지를 확인했습니다. 새 설치본의 준비됨→원래 OFF/끔 복원과 일반 재생·채팅 유지도 확인했지만, 실제 자연 삭제 이벤트는 미검증입니다.

- 삭제된 채팅 표시의 라이브 후보는 연결 준비 상태와 실제 삭제 표시 검증을 구분하며, 연결 계약이 없거나 VOD이면 지원 제한입니다. 사이드바 자동 갱신·팔로잉 펼침은 현재 기본 사이트 버튼으로 보완했고 기본 설치본 검사를 기록했으나 모든 변형을 보장하지 않습니다.
- 통계는 해상도와 측정 FPS를 제공하며, 확인되지 않은 비트레이트/지연시간은 알 수 없음으로 표시합니다.
- 컴프레서는 안전하게 연결 가능한 같은 origin의 blob 영상만 지원합니다. 오디오 자동재생 정책에 따라 버튼을 다시 눌러야 할 수 있습니다.
- HLS 미리보기는 네트워크·브라우저 코덱·권한에 영향을 받으며, 연령 제한 방송은 재생하지 않습니다.
- 실제 설치한 Chrome의 전체 기능 검증은 아직 완료되지 않았습니다. Firefox는 복구판 지원 대상이 아닙니다.

### 개발 및 검증

#### 로컬 점검 도구

모델 보안검토와 별도로 알려진 의존성 권고, 정적 코드 패턴, 비밀정보 노출을 점검합니다. `npm ci --ignore-scripts`로 고정된 개발 의존성을 설치하고, [Gitleaks 8.30.1](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1)의 운영체제에 맞는 실행 파일을 준비합니다. Windows x64 ZIP의 공식 SHA-256은 `d29144deff3a68aa93ced33dddf84b7fdc26070add4aa0f4513094c8332afc4e`입니다. 다른 운영체제는 해당 릴리즈의 checksums 파일로 확인합니다.

```powershell
$env:TOOL_AUDIT_GITLEAKS = 'C:\tools\gitleaks-8.30.1\gitleaks.exe'
npm run audit:tools
```

이 작업 폴더에는 해시 확인한 npm 12.2.0과 Gitleaks 8.30.1을 ignored `output/tool-audit/tools`에 설치했습니다. 여기서는 `node scripts/tool-audit.mjs`로도 실행할 수 있습니다. 설치 파일은 커밋되지 않으므로 새 클론에서는 위 준비가 필요합니다. 직접 실행할 때 다른 npm CLI를 쓰려면 `TOOL_AUDIT_NPM_CLI`에 `npm-cli.js`의 절대 경로를 지정합니다.

보고서는 실행마다 새 `output/tool-audit/run-*` 폴더에 저장하며 자동 수정하지 않습니다. 필요하면 `--only=npm`, `--only=eslint`, `--only=gitleaks`로 분리합니다. 종료 코드 0은 해당 도구·범위에서 탐지 없음, 1은 미해결 경고, 2는 미실행·실패·불완전 보고서입니다. 경고와 오류를 예외 처리 없이 그대로 유지하고, 비밀정보 보고서에는 비밀값·매칭 원문·작성자 정보가 남지 않도록 필드를 제한합니다.

npm 점검은 개발 의존성까지 포함하며 공개 npm 레지스트리에 패키지 정보를 전송합니다. ESLint와 Gitleaks는 로컬에서 실행합니다. 정적 검사 대상은 자체 root/web/scripts 코드이며 vendor·node_modules·테스트·생성 파일 및 `scripts/hls-hardening.mjs`, `scripts/vendor-hls.mjs`는 제외합니다. Gitleaks는 생성·개인 작업 폴더를 제외한 현재 파일과 로컬 전체 Git 이력을 검사합니다. 정적 경고는 확정 취약점이 아니며, 의존성 점검은 로컬 수정된 HLS 번들을 분석하지 않습니다. 기존 미확정 HLS 후보 검증, 침투·재현 시험, 제품 전체 안전성 인증을 대신하지 않습니다.

2026-10-11 최초 도구 점검에서 npm 영향 패키지 경고는 16개(Critical 3), 정적 경고는 77개였습니다. 기존 범위 안의 개발 의존성 갱신과 `fx-runner`의 `shell-quote` 1.12.0 override, DOM SVG 구성·worker import 검사·webpack callback 명명 보완 뒤 각각 3개(Critical 0)와 74개가 남았습니다. npm 잔여 3개는 `web-ext → @devicefarmer/adbkit → node-forge` 경로이며 당시 공식 최신 node-forge 1.4.0도 권고 영향 범위였습니다. 자동으로 제안된 web-ext 5.1.0 다운그레이드는 적용하지 않았습니다. 정적 잔여는 객체 동적 접근 43건·동적 파일 경로 31건으로, 전부 오탐이라고 판단하거나 숨기지 않았습니다. Gitleaks 두 범위의 탐지는 0건이었지만 모든 종류의 비밀정보가 없다는 보장은 아닙니다. 이 결과는 날짜와 검사 범위가 한정된 기록입니다.

Node 24 계열은 24.15.0 이상에서 `npm ci`, `npm test`, `npm run check`, `npm run build`를 실행합니다. 전체 테스트 명령에는 보류된 HLS 전용 검사도 포함되므로 위의 HLS 제외 회귀 결과와 구분하며, 해당 보류를 해제하는 명령으로 취급하지 않습니다. 배포에는 node_modules·테스트·백업 파일을 포함하지 않습니다. HLS 출처/라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.

후속 도구 실행의 `summary.json`에는 경고별 위치·규칙·npm 권고 출처와 미해결 상태를 보존한 `catalog`가 포함됩니다. 도구 경고를 자동으로 확정하거나 오탐으로 종결하지 않습니다. 자체 정적 코드·package.json·lockfile·검사 설정의 실행 전후 SHA-256 목록을 기록하고, 전후 내용이 다르면 종료 코드 2로 처리합니다. 이는 파일 잠금이나 저장소 전체의 원자적 스냅샷이 아니며, Gitleaks 대상 전체를 동결하는 것도 아닙니다. 입력 지문을 읽는 실행기 코드 자체에 동적 파일 경로 경고 1건이 추가되어 후속 정적 경고는 75건입니다. 이 경고도 숨기지 않습니다. Chrome·Firefox 빌드 계약에는 개발 의존성과 점검 보고서가 확장 산출물에 포함되지 않는 회귀 검사를 추가했습니다. node-forge 경고의 개발 도구 경로가 남아 있다는 사실과 확장 산출물에 해당 의존성을 넣지 않는 사실은 별도로 기록합니다.

[설치본 필터 충돌과 보완 기록](docs/superpowers/validation/2026-10-08-restored-settings-and-runtime-checks.md)에 실패·회귀·남은 설치 검증을 구분했습니다.

2026-10-11 설정 저장 경로 변경 후 이 검사 스크립트의 구형 가짜 저장소 입력에서 밝기 0의 필터 개수가 1 대신 0인 실패를 재현했습니다. 시험 저장값을 먼저 갱신하고 변경 알림 뒤 생산 코드의 재조회 완료를 기다리도록 검사 환경만 보완했습니다. 픽셀 기대값·필터 보존·중복 적용·초기화 검증은 완화하지 않았으며 Chrome 155.0.8059.39에서 17/17을 통과했습니다. 같은 후속 단계의 HLS 전용 테스트 파일을 제외한 Node 회귀는 391/391 통과했습니다. 전체 HLS 검사나 설치본 수용 결과가 아니며, 이 검사 환경 보완은 제품 코드와 기존 dist를 변경하지 않습니다.

[홈 추천 방송 숨김 후보](docs/superpowers/validation/2026-10-08-home-recommendation-recovery.md)는 일반 홈의 상단 추천 grid만 숨기고 편집 추천 콘텐츠·팔로잉·최근 다시보기는 보존합니다. 좁은 화면 재렌더 결함을 보완해 Node 101개·native CSS 40개를 통과했고, 새 설치본에서 임시 CSS 없이 좁음↔넓음 재렌더·화면 전환·저장 옵션OFF 원복/ON 복원을 확인했습니다. [추가 설치본 검사](docs/superpowers/validation/2026-10-08-installed-remaining-function-checks.md)에서 전체 화면/Esc는 사용자 직접 정상 확인했고, 시작 시각 연결점 불일치도 후속 보완을 검증했습니다. 나머지 전체 수용은 계속 진행 중입니다.

[플레이어 스타일 검사](docs/superpowers/validation/2026-10-08-style-baseline-and-acceptance.md)에서 버튼 숨김·볼륨 표시의 설정 반전/원복을 확인했고, 현행 VOD ‘플레이어 영역 채우기’의 구형 선택자·인라인 높이 제한 결함을 보완했습니다. 당시 Node109개·native CSS49개와 실제 VOD 임시 규칙 A/B를 통과했고, 새 설치본의 저장 옵션ON도 임시CSS 없이 일반/넓은 화면에서 기본 수용하고 원래OFF 복원까지 확인했습니다. 이 기능은 플레이어 컨테이너의 세로 높이 제한만 완화하며 전체화면·영상 확대/잘라내기·화질 변경 기능이 아닙니다. 채팅 글꼴의 닉네임 배지 크기 결함도 제한 보완해 Node109개·native CSS58개·실제live/VOD 임시A/B를 통과했고, 새 설치본에서도font8의 배지·복수배지·이모지 크기를 임시CSS 없이 기본 수용했습니다. 원래 채팅 설정 복원과 사이드바/나머지 전체 검사는 진행 중입니다. 타임머신은 현재 계정 조건으로 실사용 미검증이며 전체 정상으로 합산하지 않습니다.

[사이드바 후속 검사](docs/superpowers/validation/2026-10-08-style-baseline-and-acceptance.md)에서 원래 채팅·사이드바 설정 복원을 확인했지만, 초기 로딩의 섹션 수에 따라 일반 메뉴까지 숨기는 결함을 발견했습니다. 현재 DOM의 숨김 4개를 실제 섹션 식별 표지에 연결하고 구형 DOM 규칙은 유지했습니다. Node120개·별도 프로필 브라우저84개(코드·CSS 통합 포함)와 빌드·패키지 검사를 통과했으며, 새 설치본 검증은 수동 확장 새로고침 후 진행해야 합니다. 전체 기능 수용과 PR 생성은 아직 미완료입니다.

[시작 시각 보완](docs/superpowers/validation/2026-10-08-start-time-selector-recovery.md)은 현재 live/VOD 연결점을 추가하고 기존 조회·캐시·취소·URL 검증을 유지합니다. 수동 새로고침 후 실제 설치본의 기본 표시·재진입·화면 전환 정리·새 카드 캐시 재사용도 확인했습니다. VOD 캡처와 모든 모드/기타 기능의 전체 수용은 별도 경계로 남아 있습니다.

사이드바 새 설치본에서 초기 일반메뉴 보존·확장 상태 숨김·기본 화면 전환을 확인했습니다. 실제 접힘에서 서비스 제목 영역 자체가 제거되는 입력을 보완해 Node122개·브라우저84개를 통과했습니다. 새 보완본에서도 임시CSS 없이 실제 접힘 숨김 유지·재로딩 후native접힘 복원·접힘SPA 전환을 확인했습니다. 남은 툴바·탐색·프로필 설정 검사와 전체 수용은 계속 진행 중이며, 자세한 실패·보완·미검증 범위는 위 사이드바 후속 기록에 남겼습니다.

툴바·탐색·배지 저장 옵션의 반전과 기본 반응형 배치를 확인했습니다. 라이브·다시보기 방송 정보의 사각 프로필 누락을 CSS 선택자2개로 보완해 Node122개·브라우저91개와 실제 임시 규칙 A/B를 통과했습니다. 이후 새 설치본에서 크기·일반 썸네일을 유지한 사각화를 확인하고 원래8개 설정을 복원했습니다. 실제 차단 방송이 없어 해당 숨김은 미검증이며 전체 정상으로 합산하지 않습니다.

필터 시험에서 현행 PZP CSS가 확장 필터를 덮는 결함을 재현해, native 영상 필터는 유지하고 영상 전용 래퍼에 확장 필터를 한번 적용하는 CSS 보완 후보를 만들었습니다. Node122·스타일91·필터17과 실제 VOD 임시 적용·제거 검사를 통과했습니다. 실제 라이브 임시 검사는 진단 제한으로 미검증이며, 새 전체 CSS 설치 수용과 중립 설정 복원에는 수동 확장 새로고침이 필요합니다. 전체 수용·최종 검토·PR은 아직 완료되지 않았습니다.

## 기능

### 탐색

- **방송 미리보기:** 마우스를 올리면 방송을 미리 볼 수 있습니다.
- **사이드바 갱신:** 30초마다 사이드바를 새로고침 합니다.
- **팝업 플레이어:** 여러 방송을 한 창에서 볼 수 있습니다.

### 플레이어

- **통계 메뉴:** 오른쪽 클릭 메뉴에서 통계를 선택하면 해상도, 비트레이트, FPS, 지연시간, 코덱을 확인할 수 있습니다.
- **방향키 탐색:** 방향키를 이용하여 짧은 시간을 되돌려 볼 수 있습니다.
- **영상 필터:** 영상 밝기, 대비, 감마를 조정할 수 있으며, 선명(샤픈) 필터를 적용할 수 있습니다.
- **오디오 컴프레서:** 큰 소리를 줄여 다이내믹 레인지를 조절하여 소리를 듣기 편안하게 만듭니다.

### 채팅

- **후원 채팅 숨기기:** 채팅창에서 치즈 후원을 숨깁니다.
- **채팅창, 폰트 크기 조절:** 채팅창의 크기와 폰트 크기를 조절할 수 있습니다.

이외에도 여러 유용한 기능을 추가하며 다양한 스타일을 설정할 수 있습니다.
