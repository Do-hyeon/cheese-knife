## 현재 배치 — 상단 두 그래프 / 하단 다이얼·페이더

후속 사용자 ‘보완 진행’에 따라 현재 대상의 전체 ON/OFF 스위치를 오디오 패널 최상단에 노출했다. 도움말 안의 플레이어 조작 예시는 삭제하고 설정 화면 Gain은1개만 남겼다. 제품 방송 화면의 간편 Gain을 삭제한 것이 아니다. 전체 OFF에서도 각 효과의 선택값·Gain·자동 켜기 설정을 보존하고 편집을 허용한다. 상태 안내는 ‘소리에 적용되지 않음’, 그래프는 ‘설정 ON/OFF · 미적용’으로 표시하며 설정 예상 특성을 실제 출력처럼 보여주지 않는다. 대상 없음 예시는 전체 스위치를 비활성화하고 기존 wanted를 보존한다. 대상 복귀로 자동 ON하지 않는다. 현재 ON은 목업의 요청 상태 예시이지 native wet 적용 성공 인증이 아니다.

상단 스위치 연결의 실제 대상 고정·늦은 상태 응답·지원 제한·요청 상태와 적용 상태 구분은 F01 상세 계획/Astra max 검토 및 native 구현·검증에서 다룬다. 목업에 Chrome API/MAIN 제어·저장 writer를 추가하지 않았다.

사용자는 EQ 곡선/핸들 통합 제안을 상단 두 그래프 분리 배치로 변경했다. 통합형은 착수하지 않았고 현재는 압축 특성→EQ 응답을 상단에서 나란히, 좁은 화면에서는 같은 순서로 세로로 보여준다. 하단 컴프레서→EQ 조작부와 읽기 순서를 맞추기 위해 DOM 배치를 바꿨으며 CSS 시각 순서만 뒤집지 않았다. SVG는 컨테이너 너비로 축을 다시 그리며 기존580px 그림을 통째로 축소하지 않는다. 아래에 Gain, 컴프레서5다이얼, EQ580px의 사각 페이더, 노멀라이저를 유지한다. 영상/프리셋과 범위 선택도 삭제하지 않았다.

- 다이얼은 시각적 원형/native range 기반이며 상대적인 위아래 드래그·숫자 입력·방향키/Home/End를 지원한다. 클릭만으로 값이 튀지 않으며 pointer cancel/창 focus 상실 시 조작을 종료한다. pointer capture 실패는 드래그를 중지하고 숫자 입력을 안내한다. 휠로 값을 바꾸는 별도 기능은 추가하지 않았다. 실제 Chrome의 native number 휠 동작·터치/capture/키보드/접근성은 미검증이다.
- 후속 승인에 따라 다이얼 계산을 시작 좌표/시작값 고정에서 직전 좌표/현재값의 증분 방식으로 바꿨다. 상·하한에서 값이 제한되더라도 직전 좌표를 갱신하여 역방향으로 즉시 반응한다. 전체 범위 이동량은240px→160px로 줄였다. 시작 높이가 달라도 같은 상대 이동은 같은 변화량이며, 화면 끝에서 한 번의 드래그로 전 범위를 갈 수 있다는 보장은 아니다. 다시 잡아 끌기/숫자 입력은 계속 필요할 수 있다.
- 컴프레서 범위/기본 의미는 그대로다. Attack·Release는ms로 표시하고 local demo 상태에서는 기존 초 단위를 유지한다. 입력 display를 고치지 않은 focus/blur로 원값을 재저장하거나 반올림하지 않는다. 컴프레서OFF는 다이얼 값을 보존하고 입력을 비활성화하며 그래프에 identity를 표시한다. 좁은/터치 화면에서는5개 조작부를3열/2열로 재배치한다.
- EQ는 평소 소수 둘째 자리까지 표시하고 직접 편집에 들어가면 보관 원값을 보여준다. 예:2.125→표시2.13→편집2.125. 빈/범위 밖 값은 기존 정상값/곡선에 반영하지 않는다. 음수 영점 표시는0.00으로 통일하고 원래 수치는 바꾸지 않는다.
- 압축 특성은 일반적인 중심 soft-knee의 **정적 참고 모형**이다. Threshold/Knee/Ratio 변화의 개념을 보여주며 실제 Chromium 전달 곡선/자동 makeup·Attack/Release 시간 반응·EQ와 합성한 방송 출력을 표현하지 않는다. 이 한계는 visible label과 접근성 설명에 명시한다. 시간 설정은 값과 다이얼만 갱신하며 정적 곡선을 바꾸는 것처럼 만들지 않는다. 실제 기능의 응답 검증/새 시뮬레이션 설계를 이 목업으로 대체하지 않는다.
- 영상 탭은5개 설정을 항목명+숫자 입력, 그 아래 전체 폭 슬라이더로 정돈했다. 밝기·대비·채도·감마의0~3/중립1, 선명도의0~10/중립0 및step any를 유지한다. 짧은 중립 눈금은 각각1/3과왼쪽 끝에 놓으며 중앙을 중립으로 오인시키지 않는다. 14px thumb 이동 구간을 고려한 CSS이지만 실제 Chrome 픽셀 일치는 미검증이다. 숫자는 평소2자리 표시/편집 시 원값이며 반올림 저장·백분율 변환·가짜 영상 미리보기·새 효과는 추가하지 않았다.
